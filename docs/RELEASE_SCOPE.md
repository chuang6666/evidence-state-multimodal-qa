# Release scope and rights

## Included

IJMLC v2 frozen numerical rankings, memberships, endpoint projections, approved base prediction values, feature/equation contracts, manuscript mappings, pure evaluation kernels, specified statistical procedures and integrity tests. Function-body receipts identify retained numerical code; relocation and table-number changes do not change metric definitions.

The source tree has independent Git history. It presents this manuscript candidate only. Public state remains **not published** until the authors authorize an actual repository release.

## Deliberately not distributed

Provider reference answers, original questions/evidence/images, external replacement-answer texts, full commercial responses, credentials, third-party weights, unpublished annotation/reviewer workbooks, and private research audits. Manuscript PDF/LaTeX and source artwork are bound by hashes but not distributed here.

Upstream transition training data/checkpoints, complete extraction/generation runners, external score/LR reconstruction inputs and all per-example resource/retrieval-reference SI inputs are not part of this numerical replay release. Mapping a supplementary frozen table does not mean reproducing its upstream experiment.

## Verified levels

- Frozen numerical replay: rankings, selection and endpoints from released projections.
- Specified statistics: fixed-score/QID-paired resampling and named tests, without refitting.
- Optional answer rescoring: supported base predictions with separately obtained provider references; external predictions need a separate authorized answer input.
- Not claimed: complete end-to-end model reproduction, independent semantic validation of natural states, exact commercial backend output reproduction, or reproduction of all supplementary upstream experiments.
